# Cotizador interno VIP

Aplicación independiente del tarifario para clientes.

Tarifa base editable: Q400 por persona y día, IVA incluido. FEE editable; referencia Alejandro Sanz 35%. Renta de referencia aprobada Q1,063.44 por semana. Total de referencia con 7 personas, un día de montaje y un día de desmontaje y fletes Q2,600: Q11,300 redondeado.

Antes de generar el PDF se requieren las revisiones de personal, renta y fletes y la confirmación final. Los avisos de validación se muestran junto al botón. Una fila adicional vacía de Q0 no bloquea la generación.

Los archivos se procesan en el navegador; esta versión extrae texto PDF y no incluye interpretación visual con IA.
