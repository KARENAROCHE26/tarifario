# Cotizador VIP de Cotyssa

Aplicación de navegador para las usuarias de Cotyssa. Logo original y tipografía Michroma/Barlow del tarifario.

Flujo: PDF de modulación, PDF/CSV de cuantificación y PDF SAP; revisión de datos, desglose editable, vista previa y PDF con precio global.

Todos los importes incluyen IVA. FEE editable (35% inicial) aplicado solo a la mano de obra. Jornada Q375; misma cuadrilla en ambas etapas; imprevistos VIP 0%; redondeo superior al siguiente Q100.

Los documentos se procesan en el dispositivo y no se guardan en este repositorio. Los borradores se guardan solo en el navegador de cada usuaria. La lectura actual reconoce texto: no incluye OCR ni interpretación visual con IA. El personal y los fletes nuevos requieren revisión, no se calculan automáticamente con un modelo validado.

Ubicación: /cotizador-vip/. La página principal del tarifario se conserva.
